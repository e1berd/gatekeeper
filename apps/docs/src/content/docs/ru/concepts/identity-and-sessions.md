---
title: Идентичности и сессии
description: Realm изолирует данные, а сессии несут уровень аутентификации.
---

Realm — граница изоляции Gatekeeper. У пользователя может быть несколько идентичностей: пароль,
passkey и социальный провайдер, связанные с одним `sub`.

Сессия содержит AAL и AMR. Чувствительная операция требует `aal2` и запускает step-up.
Короткоживущие access token проверяются по JWKS. Непрозрачные refresh token хранятся только как
SHA-256-хеши, ротируются при каждом обновлении, а повторное использование отзывает всё семейство
сессии.

Токен содержит `iss`, `aud`, `exp`, `nbf`, `sub`, `sid`, `realm`, `aal`, `amr`, `org`, `roles`, `pv`
и `act`. Idle expiry продлевается при refresh, абсолютный срок — нет.
