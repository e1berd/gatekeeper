---
title: Архитектура
description: Один контракт, три HTTP-поверхности и три схемы PostgreSQL.
---

`packages/contract` — источник истины API. Он содержит только определения, без доступа к базе и
серверной логики. Сервер и SDK зависят от него, поэтому изменения контракта проверяются типами.

| Поверхность | Путь      | Клиент                                          |
| ----------- | --------- | ----------------------------------------------- |
| RPC         | `/rpc/*`  | JavaScript SDK с сохранением `Date` и `bigint`. |
| REST        | `/api/*`  | Не-TypeScript клиенты и генераторы.             |
| Forms       | `/form/*` | Обычная браузерная навигация и cookie.          |

`auth` хранит идентичности, `rbac` — организации, роли и grants, `audit` — append-only журнал.
Стандартизированные URL, например JWKS и OAuth callback, обрабатываются обычными HTTP-маршрутами.
